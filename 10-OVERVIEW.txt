1. 🤖 DYNAMIC MODEL SELECTION
   • Switch between GPT-4o and GPT-4o-mini at runtime
   • Based on message prefix (CEO: vs CUSTOMER:)
   • 10-80x cost difference per query

2. 📝 DYNAMIC SYSTEM PROMPTS
   • CEO: Executive-focused, strategic, comprehensive
   • Customer: Overworked, dismissive, minimal effort
   • Dramatically different behaviors from same base model

3. 🔄 MULTI-AGENT COORDINATION
   • Two separate agents with distinct configurations
   • Programmatic routing based on context
   • Single interface, multiple backends

4. 💰 COST OPTIMIZATION
   • Route expensive queries to premium model
   • Route cheap queries to budget model
   • Real-world production pattern (when done ethically)

5. 🎭 SATIRICAL COMMENTARY
   • Exaggerates real-world phenomena
   • Highlights ethics of tiered support
   • Teaching through humor
